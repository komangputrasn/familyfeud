Drop your own sounds in this folder. The board picks them up by file name
(.mp3, .wav, .ogg or .m4a) the next time a question starts or the page reloads.

  drumroll.mp3   plays before the top answer is revealed
  reveal.mp3     plays when an answer is revealed   (optional)
  strike.mp3     plays on a wrong answer            (optional)

Any file that is missing falls back to a built-in synthesized sound.

The top answer is revealed when the drum roll track ends. If your track has
its big hit earlier than the end, set "Reveal at" in Admin > Settings to the
number of seconds into the track where the hit lands.
